# 拾題：重新設計與相容邊界

## 以一名 Form 6 學生的一天為單位

設計以資訊架構和學習流程為先，不套用後台模板。視覺系統以冷中性底色、白色閱讀面與靛藍操作色區分層級，錯誤與完成狀態使用獨立的語義色；標題、長文及控制項均採用系統無襯線字體，不載入外部字體。首頁重組主要行動與科目入口，答題選項、錯題解析、原卷及記錄沿用一致的間距和控制項。演示提示隨內容捲動，減少小螢幕固定區域佔用。

- **今天**：首先繼續未交草稿；沒有草稿時，從實際題庫安排小份量再練。手機預設短選擇題，較大畫面可包含主觀題。其次才是待複習課題、閱讀入口與最近一次已保存練習；不把沒有行動價值的大數字當首頁。
- **練習**：明確選科目、年份和課題；也能從搜尋結果、單題或原卷錯題發起精確重做。保留完整課題、隨機組卷、選擇題篩選和部分提交。
- **錯題本**：科目 → 課題 → 篩選／單題。題目、原答、錯因、正解、給分點、最近重做、概念筆記分層閱讀。概念回憶和筆記不是考試，不產生作答或掌握證據。
- **批改卷**：科目 → 年份／指定試卷 → 閱讀器。保留頁碼、縮圖、章節、下一道錯題、放大，以及原卷題號 → 單題重做 → 回原頁。單題詳情另有精確原卷入口。
- **記錄**：保存過的答題原文與核對方式在最前；再呈現週期報告、長期記錄、待再練和同步／備份工具。不把原卷分、重做分與長期掌握混成一個分數。

## 一次練習的閉環

1. 題數與返回位置由路由清楚保留；輸入即保存原有相同 ID、相同草稿鍵，離開後首頁可繼續。
2. 題目正文中的 A–D 選項整行可點擊、支援鍵盤；不再重複兩排選項。主觀題保留分步、自由作答及紙上作答標記。
3. 「只交已答」不把空白題當作零分。提交時固定本次作答快照，所有原輸入鎖定，清楚進入核對階段。
4. 新版先呈現結果、原答／錯因／正解及給分點，而非把長份原題和解析接成無止盡頁面；仍可展開唯讀本次答卷。
5. 選擇題按正確選項；主觀題只有已核實給分規則才自動彙算，否則要求學生明確自評。AI 輔評仍屬可選、獨立輔助，不冒充正式分數或獨立掌握。
6. 保存之後直接回單題解析、接著做剩餘題、返回原卷／原位置或看記錄。記錄中的單題也可精確返回錯因與原卷。

## 不同裝置不是等比縮小

- 桌面：頂部五入口，內容有受控行寬；首頁雙欄，練習／題目以閱讀為中心，年份與課題使用空間分工。
- 平板：壓縮邊距並調整欄數；窄平板使用底部導航，試卷保持可讀的全寬頁面。
- 手機：五個底部入口、44px 以上主要控制項、安全區留白；首頁優先一次短任務，原卷工具縮成緊湊兩行；題目、解析、表格及公式容器不推寬整頁。
- 無障礙：語意化導航／標題、當前頁標記、略過導航、可見鍵盤焦點、選項鍵盤操作、錯誤與狀態 live region、原生表單與對話框、減少動態偏好。未宣稱完成正式 WCAG 稽核。

## 資料及登入相容

正式版沿用原 localStorage 鍵、Kyle 舊無後綴資料、Yeelam 帳號後綴、題目 ID、路由、雲端格式及登入 API。沒有清空、改名或重新編號私人資料。演示版共用根目錄程式，只有合成資料與獨立 `dse_demo_` 儲存適配器；模擬 API 拒絕對外連線，不預先虛構已完成練習。

保留每欄 `changedAt` 與 `deletedAt` 墓碑的合併方式。保存提交只清除與已交快照相同、且沒有更新的欄位；另一台裝置較新的答案保留。未提交草稿、待核對快照、閱讀位置及長期掌握不因雙週統計換期被刪除。所有日期和週期是 UTC+8 北京時間。

重設計中額外補上的安全修正：

- 客戶端與 Worker 一致地合併「當期＋歸檔」四份歷史，再按較新週期邊界分類；避免舊裝置把同一記錄在兩區重複復活。精確結果不同的同時刻提交不會被時間線吞掉。
- 換期計時在所有路由啟動；跨午夜先確保換期，再計下一個邊界。直入練習／記錄也有效，且不卸載正在作答或核對的畫面。沒有舊週期鍵的歷史資料也正常歸檔。
- 備份新增 `userId`；禁止跨帳號匯入。同帳號匯入先驗證、保存帳號專屬回滾副本，再合併而非覆蓋。舊備份缺帳號時，要求先核實來源並輸入帳號，再明確確認；空間不足、格式錯誤或取消均不改資料。
- 待核對指紋包含獨立的 MC 正確選項、給分版本與正規化 ALL／ANY 加權規則。規則修訂不沿用舊待核對分數；既有保存記錄仍保留原始事實。
- 原卷閱讀位置在工具列由非固定轉為固定時，會有界地重新對齊同一頁及頁內位置，避免重整後偷偷跳頁。

## 可重跑的驗證

```bash
node --test *.test.mjs sync-worker/worker.test.mjs
python3 -B tests/redesign_browser.py --suite all --screenshots
```

[Node 資料回歸](../notebook-data.test.mjs) 使用合成時鐘、資料、儲存和檔案匯入，斷言沒有真網路請求。[瀏覽器回歸](../tests/redesign_browser.py) 使用真正的 Chrome／Chromium 與 Python 標準庫 CDP，僅提供公開原始碼和合成 API，拒絕私人目錄及外網；覆蓋五種視口、登入錯誤／過期、載入與同步故障、草稿／部分交卷／自評、試卷定位、相同 origin 下兩帳號來回切換，以及實際演示版。

截圖與測試輸出寫到系統暫存目錄，不提交學生資料或執行時儲存。CI 保存合成截圖產物；Pages 發布檢查逐一比較兩個入口與實際引用的版本化資產，不再檢查已退役的角色主題。

### 沒有代替真實驗收的部分

沒有為這次設計讀取私人題庫、原卷、學生作答或成績；因此大型真實題庫、特定掃描卷／既存批注、真實帳號的實機多裝置同步，仍需要學生在登入後驗收。沒有宣稱真實成績、掌握提升、私人試卷排版全部通過，也沒有用合成結果冒充真實學習證據。自動化覆蓋使用真正 Chrome 的響應式視口，不等同於實體 iPhone／Safari 或完整輔助技術測試。

正式發布沿用 main 根目錄 GitHub Pages；Worker 改動沿用既有受保護 secrets 的部署工作流。舊視覺資產留在版本歷史相容範圍，但新入口不載入它們；演示版的重複舊程式已移除，避免兩套引擎逐漸分叉。
